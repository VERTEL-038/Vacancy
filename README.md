# Анализатор вакансий

Проект для анализа вакансий с использованием:
- Двусвязного списка
- Бинарного дерева поиска
- Быстрой сортировки и бинарного поиска

## Структуры данных
- `core.py` — Vacancy + DoublyLinkedList
- `tree.py` — Binary Search Tree
- `utils.py` — Вспомогательные функции
- `data.py` — Тестовые данные
- `ui.py` — Пользовательский интерфейс
