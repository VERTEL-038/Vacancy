# Анализатор вакансий

Консольное приложение для хранения, поиска и анализа вакансий.

# Функционал

1. Просмотр всех вакансий
2. Поиск вакансий по диапазону зарплат
3. Поиск вакансии по точному названию
4. Топ-5 самых востребованных навыков
5. Расчет средней зарплаты по всем вакансиям
6. Добавление новой вакансии
7. Выход из программы

# Структура проекта

1. `main.py` — главный файл, запуск программы и инициализация данных
2. `core.py` — основные классы (`Vacancy` и `DoublyLinkedList`)
3. `tree.py` — бинарное дерево поиска по зарплате (`BinarySearchTree`)
4. `data.py` — тестовые данные с 20 вакансиями
5. `utils.py` — вспомогательные алгоритмы (быстрая сортировка, бинарный поиск и др.)
6. `ui.py` — пользовательский интерфейс и все меню
7. `README.md` — документация проекта

# Описание работы

Проект демонстрирует использование нескольких важных структур данных и алгоритмов:

- **Двусвязный список** (`DoublyLinkedList`) — используется для хранения вакансий в порядке добавления.
- **Бинарное дерево поиска** (`BinarySearchTree`) — позволяет быстро искать вакансии по диапазону зарплат.
- **Класс `Vacancy`** — инкапсулирует данные одной вакансии.
- **Быстрая сортировка** и **бинарный поиск** — используются для поиска вакансии по названию.
- **Частотный анализ** — для определения самых популярных навыков.

Все структуры данных работают вместе: при добавлении новой вакансии она одновременно попадает и в двусвязный список, и в дерево поиска.
